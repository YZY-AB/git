# git

个人 Git 仓库，用于存放日常练习与整理的代码、笔记。

## 目录约定

- 仓库根目录保持整洁，只保留源码、文档与必要的配置文件。
- `.gitignore` 已按「操作系统 / 编辑器 / 日志 / 密钥 / 各语言构建产物 / 大体积二进制」分层配置，新增规则请归入对应小节。
- 本地环境变量使用 `.env`（已被忽略）；如需给他人参考，提交 `.env.example`。
- 密钥、证书、`node_modules/`、虚拟环境、编译产物、压缩包与安装包一律不进版本库。

## 使用

```bash
git clone https://github.com/YZY-AB/git.git
cd git
```
